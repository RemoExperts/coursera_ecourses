# coursera_ecourses

Dedicated repo for our Coursera e-course on human data work for AI. It holds the interactive course modules as self-contained HTML files.

## What's here

Each file is a complete, standalone module. Open it in a browser; there is no build step, no server, and nothing is sent anywhere. Learner progress and quiz answers stay in the browser.

| Track | Module | File |
| --- | --- | --- |
| Audio AI | Module 1 — How Machines Learn From Sound | `module 1 ecourses/Audio_Course_Module_1.html` |
| Robotics / Embodied AI | Module 1 — Where Human Data Work Fits in Robotics | `module 1 ecourses/Robotic_Module1.html` |
| Vision-Language Models | Module 01 — Intro to Visuals in AI | `module 1 ecourses/module_1_VLM.html` |

Each module runs about 20–25 minutes and mixes short reading with interactive drills (flip cards, drag-and-drop, sliders, simulations) and knowledge checks.

## Layout

```
module 1 ecourses/   Module 1 for each track
```

Later modules will follow the same pattern, one folder per module.

## Editing

The HTML files are hand-authored and contain their own CSS and JavaScript. Edit the file directly and reload it in a browser to check the result.
